# CLAUDE.md — LAMINA

PCB **design** studio (board shape/colour/holes/graphics/copper art/parts, one board or a two-board sandwich, 3D preview, exports for JLCPCB, KiCad, DipTrace, FlatCAM, Blender, CNC).
Owner intent: design-first but technically correct — the output must not bite later at the fab or in KiCad/DipTrace.

## Run / test
```bash
./serve.sh            # browser: http://localhost:8790  (no build, plain ES modules)
./run.sh              # Electron shell if an electron runtime is found (./.electron/, ../stickfigures/.electron/, PATH), else serve.sh
node test/run-all.mjs # every test/*.test.mjs (gerber/excellon/gcode/kicad/dxf/svg/pdf/library/hershey…) → ALL PASS
# in-browser: http://localhost:8790/?selftest   (add &stay3d to end on the 3D view) — prints ALL PASS overlay + console
# headless:  chromium --headless=new --use-gl=swiftshader --enable-unsafe-swiftshader --enable-logging=stderr --virtual-time-budget=30000 'http://127.0.0.1:8790/?selftest' 2>&1 | grep -A40 SELFTEST
#   (add --run-all-compositor-stages-before-draw when screenshotting the 3D view, or the WebGL canvas captures blank)
```
kicad-cli (Flatpak shim at ~/.local/bin/kicad-cli — it unsets APPDIR/APPIMAGE, and the Flatpak cannot see /tmp, so tests write under ./.tmp/) is used by test/kicad.test.mjs to prove exported boards load.

## Architecture (read docs/FORMAT.md first — it is the contract)
- `js/model.js` document + `Store` (undo/redo snapshots, transactions for drags, selection, events). File = `.lamina.json` (format `lamina/1`).
- `js/geom.js` **the resolver**: `resolveBoard(board, doc, opts)` flattens items+parts+stack links into per-layer prims (`line/polyline/arc/circle/poly/text/image`), drills, pads, parts. Every renderer/exporter consumes ONLY this. Coordinates mm, Y up, top-view frame; bottom text mirrored.
- `js/library.js` (+ `js/lib/parts_hardware.js`, GENERATED by `node tools/build_hardware_lib.mjs`: a K() block loads `lib-src/kicad/*.kicad_mod` official KiCad footprints verbatim, and a RESEARCHED block hand-authors ~85 pedal/synth parts from datasheets + KiCad + JLCPCB/EasyEDA footprints (pots 9/16 mm, EC11, Thonkiconn, NMJ6HCD2, DC-005, USB-C/micro-B/A, terminals, JST, tact/toggle/3PDT/slide/DIP switches, LEDs, OLED/1602, ESP32/Pico/Nano/Daisy/D1 modules, low-profile/stackable/long-pin headers); `verify:true` marks parts whose numbers were not read from a drawing — the desc says what) footprints (docs/LIBRARY.md schema), parametric generators (`hdr_1x08`, `fhdr_2x10`, `dip_16`, `soic_8`, `b2b_hdr_1x08`/`b2b_hdr_lp`/`b2b_hdr_stack`/`b2b_longpin`/`b2b_pinstrip` stack pairs — gap ranges are derived in the notes inside the generator), `getFootprint(id)`. Edit the generator, not the generated file. `examples/*.lamina.json` come from `tools/make_examples.mjs`; open with `?load=examples/pedal-sandwich.lamina.json[&board=1][&view=3d][&flip=1]`.
- `js/lib/fonts.js` (GENERATED by `tools/build_fonts.mjs` from `lib-src/hershey/*.jhf`) 21 stroke fonts; `fontStrokes(fontId, text, size, opts)` is what `geom.textPrimsToPolylines` calls (text items carry `font` and `arc`). `js/lib/clip.js` raster-backed area engine (booleans/offset/morphology + generators) behind `js/effects.js` (the Design studio: generators fill `usableArea` = board − cutouts − drills − pads − courtyards − margins; effects transform the selection). `js/match.js` footprint similarity + unmatched-part detection, `js/fppreview.js` footprint thumbnails.
- `js/render.js` canvas renderer (realistic + layers modes) shared by editor, PNG/JPEG export and 3D textures. `js/editor2d.js` tools/handles/selection. `js/view3d.js` three.js scene (`buildScene` also used by STL/OBJ/GLB export). `js/drc.js` presets (JLC values researched) + stack checks. `js/panels.js`, `js/wizard.js`, `js/app.js` UI shell + export dialog + autosave (localStorage).
- `js/export/*` one module per format, all `export fn(doc, opts) → [{name,data}]` (docs/EXPORTERS.md); `common.js` has a dependency-free ZIP writer. `js/import/*` KiCad board/footprint, DipTrace ASCII board (`diptrace.js` — reverse-engineered `.asc`: coordinates are 1/3 mm, Y down, pads pre-rotated, pattern silk normalised to Width/Height; test/fixtures/diptrace-mini.asc is a real export), SVG, images.
- Stack (two boards): `doc.stack = {enabled, gap, links[]}`; links are standoffs/connectors that exist on both boards; parts with `through:true` on the lower board add a hole to the upper board (`stackLinkItems` in geom.js). Gap = clear distance between facing surfaces = standoff length; connector pairs carry min/nominal/max gaps.

## Conventions / gotchas
- No bundler, no npm deps at runtime; three.js r170 + addons are vendored in `vendor/` with relative imports.
- Text is a stroke font (Hershey Simplex, `js/lib/hershey.js`); `size` = cap height. Never rasterise text for exports.
- Bottom-side items are stored in top-view coordinates (like KiCad/Gerber). Only the *view* flips.
- Gerber = Protel extensions in `gerber/<board>/`; Excellon METRIC decimal, PTH and NPTH separate files. KiCad export puts the board at (20,20) mm, Y down.
- Item types include `path` (open polyline on any layer) — generators emit those; exporters see them as `polyline` prims, so no exporter changes were needed.
- Keep `?selftest` green and `node test/run-all.mjs` green after touching geom/model/exporters.
